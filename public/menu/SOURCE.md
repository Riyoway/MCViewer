Menu textures and bitmap fonts extracted from the user-provided Minecraft-1.12.2-js.html (Eaglercraft 1.12.2 Offline), embedded EPK v2 resources. Original texture pixels preserved. Extraction: npm run menu-assets -- <path-to-html>.
Slider track and handle use the native GuiOptionSlider 150 x 20 and 8 x 20 slices (https://github.com/WangTingZheng/mcp940/blob/master/src/minecraft/net/minecraft/client/gui/GuiOptionSlider.java).
English inventory names in item-names.json come from the official Minecraft 1.13 client en_us.json and minecraft-data for newer IDs. Regenerate with npm run ui-language.
